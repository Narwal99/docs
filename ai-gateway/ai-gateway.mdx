## Supported Model Types

AI Gateway supports multiple categories of models for common AI workloads.

| Model Type | Typical Use Cases | Billing Unit |
| ---------- | ----------------- | ------------ |
| Language models | Chat, reasoning, coding, summarization, tool calling, and structured output | Input and output tokens |
| Long-context language models | Document analysis, large codebase analysis, and retrieval-augmented generation | Input and output tokens, sometimes tiered by context size |
| Claude-series models | Chat, coding, reasoning, and workflows that use prompt caching | Input tokens, output tokens, cache writes, and cache reads |

## Pricing

**AI Gateway provides two service plans**: Enterprise for production workloads and Developer for individual or experimental use. Model prices are listed in USD. Always use the unit prices displayed in the console as the source of truth.

### Language Models

General language models are billed by token usage.

| Usage Type | Unit Price |
| ---------- | ---------- |
| Input tokens | `$XX.XX` / 1M tokens |
| Output tokens | `$YY.YY` / 1M tokens |

Billing formula:

```text
Total cost =
  (input tokens / 1,000,000 × $XX.XX)
+ (output tokens / 1,000,000 × $YY.YY)
```

### Tiered Context Pricing

Some language models select a pricing tier based on the total number of input tokens in a request. After the tier is selected, its input and output prices apply to the entire request.

| Context Tier | Input Tokens per Request | Input Token Price | Output Token Price |
| ------------ | ------------------------ | ----------------- | ------------------ |
| Standard context | Up to the model's tier threshold | `$XX.XX` / 1M tokens | `$YY.YY` / 1M tokens |
| Extended context | Above the model's tier threshold | `$AA.AA` / 1M tokens | `$BB.BB` / 1M tokens |

Standard-context formula:

```text
Total cost =
  (input tokens / 1,000,000 × $XX.XX)
+ (output tokens / 1,000,000 × $YY.YY)
```

Extended-context formula:

```text
Total cost =
  (input tokens / 1,000,000 × $AA.AA)
+ (output tokens / 1,000,000 × $BB.BB)
```

The exact threshold and prices vary by model and are displayed in the console.

### Claude-Series Prompt Caching

Claude-series models may include prompt caching charges in addition to normal input and output token charges.

| Usage Type | Unit Price |
| ---------- | ---------- |
| Input tokens | `$XX.XX` / 1M tokens |
| Output tokens | `$YY.YY` / 1M tokens |
| Cache write, 5-minute TTL | `$MM.MM` / 1M tokens |
| Cache write, 1-hour TTL | `$NN.NN` / 1M tokens |
| Cache read | `$ZZ.ZZ` / 1M tokens |

Billing formula:

```text
Total cost =
  (input tokens / 1,000,000 × $XX.XX)
+ (output tokens / 1,000,000 × $YY.YY)
+ (5-minute cache write tokens / 1,000,000 × $MM.MM)
+ (1-hour cache write tokens / 1,000,000 × $NN.NN)
+ (cache read tokens / 1,000,000 × $ZZ.ZZ)
```

## Usage Notes

- Check the console for the latest model list, supported parameters, context limits, and real-time prices.
- For language models, estimate cost from both input and output tokens. Long prompts, retrieved documents, and tool results can increase input token usage.
- For tiered-context models, the input token count determines which price pair applies to the entire request.
- For cached prompts, cache writes and cache reads may appear as separate billable usage types.
- Use rate limits and budget controls when integrating AI Gateway into production applications.
